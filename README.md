# Доска Гальтона: Распределение Максвелла — Гаусса

Интерактивная 3D-лабораторная установка и программный комплекс для изучения статистических закономерностей, центральной предельной теоремы и распределения Гаусса на доске Гальтона.

## 🎯 Основные возможности

### 1. 3D-модель доски Гальтона (`Three.js`)
* **Геометрия установки:** 14 рядов штырьков, 15 приемных каналов (координаты ячеек $x_i = 1 \dots 15$, центр $x_0 = 8$).
* **Физика рассеяния:** Моделирование упругих соударений шариков со штырьками, учет угла наклона доски (от $-10^\circ$ до $+10^\circ$), регулировка скорости и темпа подачи шариков.
* **Голографическая визуализация:** Интерактивная 3D-голограмма теоретической кривой Гаусса и текущей гистограммы накопления.
* **Лабораторные инструменты:** Встроенная миллиметровая шкала (линейка) и снятие высот столбиков $h_i$ (мм) в реальном времени.

### 2. Лабораторный модуль статистической физики
* **Расчёт базовых характеристик:**
  * Суммарная высота $H = \sum h_i$ и калибровка числа шариков $N = k \cdot H$.
  * Относительные частоты $w_i = h_i / H$ с полной погрешностью $\Delta w_i = \sqrt{\Delta w_{\text{приб}}^2 + \frac{w_i(1-w_i)}{N}}$.
  * Математическое ожидание $\langle x \rangle \pm \sigma_{\langle x \rangle}$ и дисперсия $D$.
  * Среднеквадратичное отклонение $\sigma \pm \Delta\sigma$ и полуширина на полувысоте $\Gamma_{0.5} \approx 2.355\,\sigma$.
* **Физическая диагностика установки:**
  * Эффективная вероятность шага вправо: $p_{\text{эфф}} = \frac{\langle x \rangle - 1}{14}$.
  * Эффективное число каскадов рассеяния: $n_{\text{эфф}} = \frac{D}{p_{\text{эфф}}(1 - p_{\text{эфф}})}$ (диагностика упругих проскоков шариков или эффекта трения).
  * Оценка наклона доски в градусах.
* **Критерий согласия Пирсона $\chi^2$:**
  * Проверка согласия с нормальным распределением $\mathcal{N}(\langle x \rangle, \sigma)$ и идеальным биномиальным законом $B(14, 0.5)$.
  * Автоматическое объединение малочисленных хвостовых ячеек ($E_m \ge 5$).
  * Проверка правила трех сигм ($\pm 1\sigma, \pm 2\sigma, \pm 3\sigma$).
* **Закон больших чисел (численный эксперимент):**
  * Исследование затухания среднеквадратичного отклонения частот: $\delta(N) \propto N^{-1/2}$ с построением графика в масштабе log–log (наклон $-1/2$).
* **Тренажёр самопроверки:** Интерактивная проверка расчётов студентов с адаптивными подсказками.

### 3. Математический движок KaTeX (100% Offline)
* Встроенная библиотека KaTeX v0.16.11 со шрифтами WOFF2 (base64).
* Красивое типографическое отображение всех математических формул без необходимости подключения к интернету.

## 📁 Структура проекта

* `index.html` — Главная страница веб-приложения (3D-доска + встроенный модуль лабораторной работы).
* `lab_work.html` — Автономный интерактивный лабораторный журнал/бланк отчёта для печати и самостоятельной работы.
* `доска_гальтона_автономная.html` / `galton_standalone.html` — Полностью автономные single-file сборки (все скрипты, 3D-движок, KaTeX, шрифты и стили объединены в один файл).
* `galton.js` — Логика 3D-сцены, физики шариков, штырьков и элементов управления Three.js.
* `lab.js` — Интерфейс лабораторной работы, отрисовка таблиц, графиков, серий опытов и тренажёра.
* `lab-core.js` — Математическое ядро расчётов статистических величин и критерия Пирсона.
* `lab-core.test.cjs` — Набор модульных тестов для верификации математических формул.
* `build_standalone.py` — Скрипт сборки автономных HTML-файлов.
* `katex/` — Автономный дистрибутив KaTeX (CSS, JS, шрифты woff2).

## 🚀 Запуск проекта

### Вариант 1: Локальный веб-сервер
Для корректной загрузки ES-модулей запустите любой HTTP-сервер в папке проекта:
```bash
# Python
python -m http.server 5500

# Node.js
npx serve .
```
Откройте в браузере: `http://localhost:5500/index.html` или `http://localhost:5500/lab_work.html`.

### Вариант 2: Полностью автономный (без сервера)
Просто откройте файл `доска_гальтона_автономная.html` или `lab_work.html` двойным кликом в любом браузере (Chrome, Firefox, Safari, Edge, Яндекс.Браузер).
